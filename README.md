# FineVu Wi-Fi · Web Demo

파인뷰 Wi-Fi 앱(Android)을 실제 블랙박스 없이 브라우저에서 시연하기 위한 웹 프로토타입입니다. (`index.html` 단일 파일)

- 시연 모델: **GX4K** (NON-LCD · Wi-Fi 목록에서 직접 연결) / **X1200 POWER** (LCD · QR 연결)
- 가상 동작: 연결, 재생 모드·설정 메뉴 진입 시 녹화 중지/재개, 녹화 방식 변경·설정 초기화·펌웨어 업데이트 후 재부팅, 스피드캠 지역 선택(GX4K), AI 충격 안내(X1200)
- 언어: 한국어 / English. PC에서는 왼쪽 데모 패널, 휴대폰에서는 오른쪽 아래 `DEMO` 버튼으로 바꿉니다. 영어로 바로 열려면 주소 끝에 `?lang=en`을 붙이세요.
- 영상: YouTube 샘플 영상을 쓰므로 인터넷 연결이 필요합니다.
